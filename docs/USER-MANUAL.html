🎯 แนะนำระบบ

POS Referral & Loyalty เป็นระบบที่ให้ลูกค้าแนะนำเพื่อน ผ่าน referral code เมื่อเพื่อนมาใช้บริการครั้งแรก ลูกค้าจะได้แต้ม และสามารถนำแต้มไปแลกส่วนลดผ่านพนักงาน

3 หน้าหลัก

👤 Customer Page สมัคร / แชร์ code / เชิญเพื่อน
🧑‍💼 Staff Page ค้นหาลูกค้า / แลกแต้ม / ยืนยัน
⚙️ Admin Page ดูรายงาน / แก้ settings

⚙️ การติดตั้ง

ตรวจสอบ prerequisites

ตรวจ Node.js + Docker

node --version   # ควรได้ v20.x หรือสูงกว่า
docker --version  # ควรได้ Docker 24+

Clone repository

git clone https://github.com/maleexl/pos-referral-loyalty.git
cd pos-referral-loyalty

ตั้งค่า Environment

cp .env.example .env                    # root — docker compose อ่านค่านี้
cp backend/.env.example backend/.env    # STAFF_API_KEY / ADMIN_API_KEY
cp frontend/.env.example frontend/.env  # VITE_API_URL
⚠️
สำคัญ: ต้องมีไฟล์ env ครบทั้ง 3
• ไม่มี root .env → docker compose up จะ error เพราะขาด POSTGRES_USER/PASSWORD/DB
• ไม่มี frontend/.env → หน้าเว็บ blank ทันที เพราะ VITE_API_URL ไม่ถูกตั้ง

Start Database (PostgreSQL)

docker compose up -d
docker compose ps  # รอสถานะ healthy

Local dev default ใช้ port 5432 — ตาม cp .env.example .env (root → POSTGRES_PORT=5432) และ backend/.env.example ชี้ DATABASE_URL มาที่ localhost:5432. Docker map "${POSTGRES_PORT:-5432}:5432" และ CI ก็ใช้ 5432 เช่นกัน. 5440 เป็นเพียง optional override เมื่อ host port 5432 ถูกใช้อยู่ — ถ้าเลือกใช้ ต้องแก้ให้ตรงกันทั้ง root .env (POSTGRES_PORT) และ backend/.env (DATABASE_URL)

ติดตั้ง Backend

cd backend
npm install
npx prisma migrate dev  # สร้าง/อัปเดต tables ตาม migrations
npx prisma db seed      # ใส่ settings 5 ค่า + admin staff เริ่มต้น
ℹ️
backend ไม่มี npm script ชื่อ migrate:deploy หรือ seed — ใช้ npx prisma … โดยตรง (หรือ npx prisma migrate deploy สำหรับ apply migrations แบบ non-interactive)

ติดตั้ง Frontend

cd ../frontend
npm install

🔌 API Docs

โปรเจกต์นี้ไม่มี Swagger UI — backend ไม่ได้ติดตั้ง @fastify/swagger (ไม่มี route /docs) สัญญา API ฉบับจริง ทั้ง request / response / auth / error code อยู่ที่ docs/API-CONTRACT.md

ทดสอบว่า backend มีชีวิต:

curl http://localhost:3000/health
# {"status":"ok","service":"pos-referral-loyalty-backend"}

Auth headers

  • /api/* และ /internal/mock-pos/* — public (ไม่ต้องมี key)
  • /staff/* — ส่ง header X-Staff-Key (ค่าจาก STAFF_API_KEY)
  • /admin/* — ส่ง header X-Admin-Key (ค่าจาก ADMIN_API_KEY)

Endpoints

📄 docs/API-CONTRACT.md (อ้างอิง)

POS Referral API v1

รายการ endpoint — รายละเอียดเต็มอยู่ในสัญญา

POST /api/customers Register a customer · public
POST /api/referrals Create a referral · public
GET /api/customers/{code} Get customer by code · public
GET /api/customers/{code}/referrals List a customer's referrals · public
GET /api/customers/{code}/rewards Rewards + points balance · public
POST /internal/mock-pos/visits Record a POS visit · dev only
POST /staff/redeem Issue a redemption · X-Staff-Key
POST /staff/redeem/confirm Confirm a redemption · X-Staff-Key
GET /admin/referrals List referrals · X-Admin-Key
GET /admin/redemptions List redemptions · X-Admin-Key
GET /admin/settings Read all settings · X-Admin-Key
PATCH /admin/settings Update settings · X-Admin-Key

↑ อ้างอิงจาก docs/API-CONTRACT.md (v1, unversioned paths)

Error envelope

ทุก error คืน JSON รูปแบบเดียวกัน (details มีเฉพาะบาง endpoint):

{"error":"Human-readable message","code":"MACHINE_CODE","details":{...}}
HTTP Code เมื่อไหร่
400INVALID_INPUTvalidation ผิด (zod)
400INSUFFICIENT_POINTSredeem เกิน balance
400UNKNOWN_SETTING_KEY / INVALID_TYPE / OUT_OF_RANGEแก้ settings ไม่ผ่าน schema
401UNAUTHORIZEDkey หาย/ผิด
403SELF_REFERRAL (FORBIDDEN)email/phone ตรงกับ referrer เอง
404NOT_FOUND / CUSTOMER_NOT_FOUND / REFERRER_NOT_FOUND / CODE_NOT_FOUNDหา resource ไม่เจอ
409EMAIL_EXISTS / PHONE_EXISTSสมัคร customer ซ้ำ
409REFEREE_EMAIL_EXISTS / REFEREE_PHONE_EXISTS / REFEREE_HAS_REFERRERreferral ซ้ำ/มี referrer อยู่แล้ว
409CODE_ALREADY_REDEEMED / REFERRAL_ALREADY_COMPLETED (CONFLICT)ทำไปแล้ว / ยืนยันซ้ำ
410GONE / CODE_EXPIRED / REFERRAL_EXPIREDหมดอายุ
500INTERNALserver error (envelope เดียวกัน)

🔧 Troubleshooting

❌ หน้าเว็บ blank (ขาว)

🔴
สาเหตุ: VITE_API_URL ไม่ถูกตั้งใน frontend/.env
แก้: cp frontend/.env.example frontend/.env → restart npm run dev

❌ CORS error ใน Console

⚠️
สาเหตุ: CORS_ORIGIN ใน backend/.env ไม่ตรงกับ frontend URL (หรือตั้งเป็นค่าว่าง → plugin ไม่ถูก register)
แก้: แก้ backend/.env → CORS_ORIGIN=http://localhost:5173 → restart backend

❌ Docker container unhealthy

docker compose ps       # ดูสถานะ
docker compose logs postgres  # ดู error (service ชื่อ postgres)
docker compose down -v  # reset (ลบ data)
docker compose up -d

❌ Migration fails

docker compose ps  # รอ DB healthy ก่อน
cd backend
npx prisma migrate deploy

❌ Port already in use

lsof -i :3000  # หา process
kill -9 <PID>  # ปิด

❓ FAQ

Q: ต้องมี account สำหรับใช้งานไหม?

A: ไม่ต้อง — ลูกค้าใช้ referral code เป็น identifier, staff/admin ใช้ API key

Q: ทำไม referral ถึงหมดอายุ?

A: ค่าเริ่มต้น 30 วัน — ตั้งค่าได้ที่ Admin → Settings → referral_expiry_days

Q: แต้มมีอายุไหม?

A: แต้มไม่มีอายุ — แต่ redemption code ที่ได้มามีอายุ 7 วัน (ตั้งค่าได้ที่ redemption_expiry_days)

Q: ใช้ POS จริงได้ไหม?

A: MVP ใช้ Mock POS — production ต้องเชื่อม POS จริงผ่าน webhook / REST

Q: รองรับหลายสาขาไหม?

A: MVP เป็น single-tenant เท่านั้น — ยังไม่รองรับ multi-branch

Q: ต้อง backup DB ไหม?

A: Local: docker compose exec postgres pg_dump -U pos_user pos_referral_loyalty > backup.sql (service ชื่อ postgres, user/db มาจาก root .env)
